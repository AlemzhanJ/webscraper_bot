# 🤖 Web Scraper Bot

Telegram-бот для парсинга веб-страниц и интеллектуального анализа контента с помощью AI (Google Gemini).

## 📋 Описание

Этот бот позволяет:
- 🌐 Парсить веб-страницы и извлекать текстовый контент
- 📄 Сохранять контент в различных форматах (TXT, PDF)
- 🤖 Общаться с AI о содержимом документа
- 📝 Создавать структурированные конспекты с эмодзи
- 💾 Кэшировать документы для быстрого доступа
- 🛡️ Защита от DoS/DDoS атак с помощью rate limiting
- 📊 Статистика использования для администраторов

## 🚀 Возможности

### Основные функции
- **Парсинг веб-страниц**: Извлечение текста с сохранением структуры (заголовки, списки, таблицы)
- **Рекурсивный парсинг**: Обход нескольких страниц по ссылкам (до 10 страниц)
- **AI-ассистент**: Задавайте вопросы о содержимом документа
- **Генерация конспектов**: Автоматическое создание структурированных конспектов с эмодзи
- **Экспорт**: Сохранение в TXT и PDF форматах
- **Кэширование**: Быстрый доступ к ранее обработанным документам

### Защита и ограничения
- **Rate Limiting**: 
  - 5 URL-запросов в минуту
  - 15 AI-запросов в минуту
  - 30 общих запросов в минуту
- **Временная блокировка**: 10 минут при превышении лимитов
- **Таймаут сессий**: 10 минут неактивности
- **Лимит запросов в сессии**: 15 запросов к AI

## 📦 Установка

### Требования
- Python 3.8+
- pip (менеджер пакетов Python)

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/AlemzhanJ/webscraper_bot.git
cd webscraper_bot
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

4. **Настройте конфигурацию**
```bash
cp config.py.example config.py
```

Отредактируйте `config.py` и укажите:
- `BOT_TOKEN` - токен вашего Telegram бота (получите у [@BotFather](https://t.me/BotFather))
- `GEMINI_API_KEY` - API ключ Google Gemini (получите на [Google AI Studio](https://makersuite.google.com/app/apikey))
- `ADMIN_IDS` - список ID администраторов (ваш Telegram ID)

5. **Запустите бота**
```bash
python bot.py
```

## 🔧 Конфигурация

### Основные параметры в `config.py`:

```python
# Telegram Bot Token
BOT_TOKEN = "YOUR_BOT_TOKEN"

# Google Gemini API Key
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"

# AI Settings
AI_MODEL = "gemini-2.0-flash"
GEMINI_API_URL = "https://generativelanguage.googleapis.com/v1beta/openai/"

# Session Settings
MAX_SESSION_REQUESTS = 15  # Макс. запросов к AI в сессии
SESSION_TIMEOUT_MINUTES = 10  # Таймаут сессии

# Rate Limiting
RATE_LIMIT = {
    "url_requests": {"count": 5, "period": 60},
    "ai_requests": {"count": 15, "period": 60},
    "general_requests": {"count": 30, "period": 60}
}

BAN_DURATION = 600  # Время блокировки (секунды)

# Admin IDs
ADMIN_IDS = [YOUR_ADMIN_ID]
```

## 📖 Использование

### Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/stats` - Статистика (только для администраторов)
- `/cache_stats` - Статистика кэша (только для администраторов)

### Основной workflow

1. **Отправьте URL** веб-страницы боту
2. **Выберите действие**:
   - 📄 Получить текст (TXT)
   - 📑 Получить PDF
   - 🤖 Задать вопрос AI
   - 📝 Создать конспект
   - 🔄 Парсить несколько страниц

3. **Работа с AI**:
   - После выбора "Задать вопрос AI" начинается сессия
   - Задавайте вопросы о документе
   - Используйте кнопки для управления:
     - 📝 Создать конспект
     - 📄 Получить текст
     - 📑 Получить PDF
     - ❌ Завершить сессию

### Примеры использования

**Парсинг одной страницы:**
```
Вы: https://example.com/article
Бот: [Показывает меню действий]
Вы: [Нажимаете "📄 Получить текст"]
Бот: [Отправляет TXT файл]
```

**Работа с AI:**
```
Вы: https://example.com/article
Бот: [Показывает меню действий]
Вы: [Нажимаете "🤖 Задать вопрос AI"]
Бот: Документ загружен! Задайте вопрос...
Вы: Какая основная тема статьи?
Бот: [AI отвечает на основе документа]
```

**Создание конспекта:**
```
Вы: https://example.com/article
Бот: [Показывает меню действий]
Вы: [Нажимаете "📝 Создать конспект"]
Бот: [Генерирует структурированный конспект с эмодзи]
```

## 🏗️ Архитектура

### Структура проекта

```
webscraper_bot/
├── bot.py              # Основной файл бота
├── ai_client.py        # Клиент для работы с Google Gemini API
├── database.py         # Модели БД и работа с SQLAlchemy
├── rate_limiter.py     # Защита от DoS/DDoS
├── config.py.example   # Пример конфигурации
├── requirements.txt    # Зависимости Python
└── README.md          # Документация
```

### Компоненты

#### 1. **bot.py**
- Обработка команд и сообщений
- Парсинг веб-страниц (BeautifulSoup)
- Управление сессиями (FSM)
- Генерация PDF (reportlab)
- Интеграция с AI

#### 2. **ai_client.py**
- Асинхронный клиент для Google Gemini API
- Обработка запросов к AI
- Форматирование промптов

#### 3. **database.py**
- Модели: User, AISession, Message, CachedDocument, CachedSummary
- Кэширование документов и конспектов
- Автоматическая очистка старого кэша
- Статистика использования

#### 4. **rate_limiter.py**
- Отслеживание запросов пользователей
- Временная блокировка при превышении лимитов
- Статистика по типам запросов

## 🗄️ База данных

Используется SQLite с SQLAlchemy ORM.

### Таблицы:

- **users** - Пользователи бота
- **ai_sessions** - Активные сессии с AI
- **messages** - История сообщений в сессиях
- **cached_documents** - Кэш обработанных документов
- **cached_summaries** - Кэш сгенерированных конспектов

### Кэширование

- Документы кэшируются по хешу URL
- Конспекты кэшируются отдельно
- Автоматическая очистка кэша старше 7 дней
- Статистика использования кэша

## 🛡️ Безопасность

### Rate Limiting
- Защита от спама и DoS атак
- Раздельные лимиты для разных типов запросов
- Временная блокировка нарушителей

### Валидация
- Проверка URL перед парсингом
- Ограничение размера документов
- Таймауты для HTTP-запросов

### Приватность
- Хранение только необходимых данных
- Автоматическая очистка старых сессий
- Кэш с ограниченным сроком хранения

## 📊 Статистика

Администраторы могут получить статистику:

### `/stats` - Общая статистика
- Количество пользователей
- Активные сессии
- Запросы по типам
- Заблокированные пользователи

### `/cache_stats` - Статистика кэша
- Размер кэша документов
- Размер кэша конспектов
- Hit rate (процент попаданий)
- Экономия запросов

## 🐛 Troubleshooting

### Бот не отвечает
- Проверьте правильность `BOT_TOKEN`
- Убедитесь, что бот запущен
- Проверьте логи на ошибки

### Ошибки AI
- Проверьте `GEMINI_API_KEY`
- Убедитесь в наличии квоты API
- Проверьте доступность API

### Проблемы с парсингом
- Некоторые сайты блокируют ботов
- Проверьте доступность URL
- Убедитесь в корректности URL
